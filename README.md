# Sistema de Gestión de Estudiantes

Aplicación simple en Java que aplica conceptos fundamentales de la Programación Orientada a Objetos (POO) para controlar la inscripción y calificación de alumnos.

## Conceptos Aplicados
* **Clases y Atributos:** Encapsulamiento de datos personales y académicos.
* **Constructores:** Inicialización de objetos.
* **Métodos y Validaciones:** Control de inscripciones duplicadas y asignación de notas.

## Estructura
* `estudiante.java`: Clase con la lógica del alumno.
* `main.java`: Clase principal para ejecutar y probar las funciones.

## Requisitos
* Java JDK 8 o superior.
